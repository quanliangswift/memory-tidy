照片与本机处理

照片访问由 iOS 授权控制，可选择有限或完整权限，并随时在系统设置调整。整理、相似照片分析及整理进度在设备上处理和保存；我们不通过自有服务器收集或上传照片。启用 iCloud 照片时，Apple 的同步行为由你的系统设置和 Apple 条款决定。

私密相册与备份

私密静态照片副本和索引使用 AES-GCM 在本机加密，密钥由 Keychain 配合设备身份认证保护；应用不接收你的 Face ID 生物识别数据。后台会遮盖并锁定私密内容，但不能阻止截图或外部拍摄。当前导入不移除系统原片。你主动导出或分享的文件可能保留位置等原有元数据；接收方和目标服务按各自规则处理文件。

保存、删除与控制

整理进度和私密文件保存在设备上。可通过应用的相关操作管理内容；卸载应用可能丢失本机数据，不会自动删除已经导出的备份或系统照片。请先导出并验证备份。有效外部备份需要对应恢复码，恢复码丢失无法找回。需要协助或提出隐私请求时，请使用本页已配置的联系邮箱；不要发送照片或恢复码。

购买与第三方

购买及恢复由 Apple StoreKit 处理。应用读取经验证的交易与权益状态以提供 Pro；我们不接收完整支付卡信息。Apple 按其隐私政策处理交易。

应用广告（条件启用）

本配置关闭应用广告。此状态须与实际发布包保持一致。

应用可条件启用 Google AdMob 广告。安装包包含 Google 广告 SDK；即使关闭广告，SDK 仍可能执行启动校验，关闭广告不等于移除了 SDK。请求广告时，Google 可能处理 IP 地址、设备信息、诊断与性能数据、广告互动以及设备或广告标识符，用于投放、衡量广告及防欺诈；具体范围取决于 SDK、配置、地区与同意选择。需取得同意的地区会先显示相应流程；可通过应用内隐私选择入口调整，涉及跨应用追踪时还需 iOS 授权。Pro 不展示广告。广告不获取照片或私密内容，照片也不会用于广告定向。

本网站与政策更新

本网站不嵌入广告、分析 SDK、追踪像素、表单或第三方字体；不设置分析 Cookie。托管服务商可能为提供网站而处理 IP 地址与访问日志，本网站由 GitHub Pages 托管，相关处理遵循 GitHub 隐私声明。本政策有变更时会更新生效日期。
